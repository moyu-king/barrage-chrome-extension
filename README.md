# Barrage Chrome Extension

一个使用[vue3](https://cn.vuejs.org/)及[@crxjs/vite-plugin](https://github.com/crxjs/chrome-extension-tools)插件开发的chrome拓展程序。给予『无宗门背景的散修』游历于各大视频资源平台时弹幕支持。

插件提供两种版本，**本地版本**和**服务版本**，本地版本无需启动服务，安装插件即可使用，而服务版本需要启动弹幕服务（[仓库地址](https://github.com/moyu-king/barrage-service)），后续也会持续拓展在线弹幕等等功能。如果只是希望能看视频有弹幕，推荐使用本地版本。

#### 1. 安装：
[下载压缩包](https://github.com/moyu-king/barrage-chrome-extension/releases)，解压完后，在chrome的拓展程序界面点击**加载已解压的扩展程序**，并选中解压后的文件夹。（需请先勾选开发者模式）

#### 2. 使用
1. 添加视频

安装完插件后，是没有视频数据的（播放列表为空），可以通过以下两种方式添加，两者都在 popup 的「搜索」页里完成：

- **搜索添加（推荐）**

  点击浏览器工具栏中的插件图标，打开 popup。默认进入「搜索」页：

  1. 选择平台（bilibili / 腾讯视频 / 爱奇艺）
  2. 输入剧集或系列名称，回车或点击搜索图标
  3. 在结果列表中点击「添加」

  添加成功后，页面悬浮条中的视频列表会同步更新，可直接进入对应平台分组查看。

  ![搜索添加视频](/images/search.png)

- **页面手动添加**

  手动添加与搜索添加共用同一个面板：自行前往目标网站的视频播放页面，比如 bilibili 的播放地址为 https://www.bilibili.com/bangumi/play/xxx ，然后打开 popup。只要搜索框还没有输入关键词，就会先看到一张「当前页面」卡片，它读取的是当前标签页的地址，页面属于受支持的平台时才会出现（平台选择器也会自动对齐到当前站点）。

  点击卡片上的「添加」，页面上会弹出「添加视频」对话框，此时视频信息已自动获取完成，名称默认取页面标题，你可以根据需求改成更好认的名字，最后点击「保存」即可。

  ![当前页面手动添加](/images/add.png)

2. 悬浮条与播放列表

  插件会在视频页面上显示一条悬浮条（默认停靠在视口右侧），**整条都可以按住拖动**，松手后会自动吸附到距离更近的一侧边缘（左 / 右），停靠的高度会被记住。

  悬浮条上从左到右依次是：

  - **播放模式气泡**：显示 `A`（自动播放模式）或 `C`（自定义播放模式），鼠标悬停后会变成切换图标，点击即可切换播放模式；自定义模式下，若播放列表面板处于展开状态，气泡上会实时显示当前播放时间。
  - **重置弹幕**：见下文「重置弹幕」。
  - **弹幕设置**：展开弹幕设置面板，见下文「弹幕设置」。
  - **播放列表**：展开播放列表面板。

  点击「播放列表」展开面板后，先在顶部选择平台分组，再点击具体的视频进入剧集列表；剧集列表右上角可以在「正序 / 倒序」之间切换，倒序时最新一季排在最前，季内集数也一并反转，这个选择同样会被记住。

3. 弹幕播放
- **自动播放模式**

  插件默认为该模式，在该模式下，只需选中对应的播放集数，然后弹幕时间轴即可与视频播放器的时间轴同步，暂停也同样生效。

  【自动播放】图例如下：

  ![自动播放弹幕](/images/auto-barrage.png)

- **自定义播放模式**

  在该模式下，播放列表面板底部会出现一套自定义播放控制条：选择对应播放集数后，可先调整好开始播放时间，再点击播放按钮；控制条提供了播放 / 暂停、快退与快进 10 秒、进度条拖动、直接输入分 / 秒跳转、循环播放开关，以及一键「重置」回到 0:00，最下方显示当前时间与视频总时长。选择剧集时会自动加载该集的弹幕并停在 0:00。

  【自定义播放】图例如下：

  ![自定义播放弹幕](/images/custom-barrage.png)

> 【自动播放模式】不是每个视频网站都会生效，所以以【自定义播放模式】作为后备方案。不生效的原因，其一，当前页面如果视频播放器不止一个，插件自动识别有可能会出现选错播放器的情况，其二，就是找不到播放器。

识别失败时插件会弹出提示，并自动切换到【自定义播放模式】：

![自定义播放弹幕](/images/error-tip.png)

4. 弹幕设置

  点击悬浮条上的「弹幕设置」图标即可展开设置面板，所有设置项都会被缓存，下次打开浏览器依旧生效：

  - **播放速度**：0.5x ~ 2x，只影响弹幕的滚动速度，不影响视频本身的播放速度。
  - **字体大小**：12px ~ 32px，弹幕行高会随字号自动调整。
  - **不透明度**：10% ~ 100%，最低 10%，避免拖到全透明后完全看不到弹幕。
  - **显示区域**：1/5、1/4、1/2、3/4、全屏，决定弹幕占据屏幕上方多大范围，区域越大，允许同时出现的弹幕也越多。
  - **弹幕密度**：20% ~ 100%，会随数值显示「稀疏 / 较少 / 标准 / 较多 / 密集」。拖到 100% 时会关闭当前平台的每秒弹幕数量限流（仅保留轨道防重叠），适合弹幕本来就不多的视频。

  面板底部提供了「恢复默认」，可以一键还原以上所有设置。

  ![弹幕设置](/images/barrage-setting.png)

5. 播放模式切换

- **全局切换**

  在 popup 的「设置」页切换播放模式，会立即同步到所有已打开的视频标签页，并将配置缓存起来，下次打开浏览器依旧生效。

  ![全局切换](/images/global-switch-mode.png)

- **页面内切换**

  点击悬浮条上的播放模式气泡（`A` / `C`），只切换当前页面，不会影响到其它已经打开的标签页；这个选择同样会被记住，之后新打开或刷新的页面会按最后一次的选择生效。

  ![页面内切换](/images/switch-mode.png)

6. 重置弹幕

  当不想显示弹幕，或者视频提前退出时（视频退出弹幕不会消失），点击悬浮条上的「重置弹幕」图标即可停止播放并将弹幕面板重置清空。

  ![重置弹幕](/images/reset.png)

7. 视频删除与重命名

  右键对应的视频标签即可弹出菜单。

  ![右键菜单](/images/context-menu.png)

8. 更新插件

在本地版本中，由于使用的是 `indexDB` 存储的数据，直接卸载重装会丢失之前的数据。正确的做法是，先下载并解压新版本压缩包，然后把**原来已加载的扩展程序目录**下的文件删除，将新的文件替换，最后点击拓展程序的更新按钮即可完成更新。

![更新插件](/images/update.png)
> 目前支持腾讯视频、bilibili 与爱奇艺，后续也会持续拓展，有建议欢迎反馈。
